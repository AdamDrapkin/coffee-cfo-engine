## Scenario A: First-store location selection

Use when the CEO is looking at possible leases or locations.

Require:
- Map screenshot.
- Candidate-location screenshots.
- Foot traffic.
- Rent.
- Deposit.
- Buildout/equipment costs if shown.
- Nearby competitor locations.
- CEO’s current cash.
- Any visible demand, demographics, or location modifiers.

Analyze:
- Recurring rent versus traffic.
- Deposit versus remaining liquidity.
- Competitor proximity.
- Panda's Coffee store proximity.
- Total startup cost.
- Estimated break-even or payback using available evidence.
- Strategic location value.
- Opportunity cost of waiting.

Output:
- Rank all locations.
- Recommend Open / Wait / Reject.
- Explain which location best supports the current phase.
- State which missing figure could change the ranking.

Never recommend based solely on highest foot traffic.

### Ledger targets
- store candidates, capital-allocation entry, decision register
